A bit about meĐôi nét về tôi

Hi, I'm Hoang — a QC Engineer with 1.5+ years in Japanese IT outsourcing. At Lampart, I test B2C e-commerce products on web and mobile, working in Agile teams of 15–30 people.

On the payment side, I own the testing of the authentication and payment steps for new payment methods on the flows assigned to me: GMO credit card with 3-D Secure, Amazon Pay, refunds, cancellations, 8%/10% tax rounding and promotions. I also verify what happens below the UI — testing APIs with Postman and writing SQL on MySQL and SQL Server to reconcile order totals between the API and the database.

As a personal project, I built Pocket QA, a Chrome extension published on the Chrome Web Store that records a tester's actions and replays them as regression tests. I graduated in Information Technology from HCMUS in 10/2025, and I'm now looking for a QC role that combines manual testing with automation.

Xin chào, tôi là Hoàng — QC Engineer với hơn 1,5 năm kinh nghiệm trong lĩnh vực IT outsourcing Nhật Bản. Tại Lampart, tôi kiểm thử các sản phẩm thương mại điện tử B2C trên web và mobile, làm việc trong các nhóm Agile quy mô 15–30 người.

Ở mảng thanh toán, tôi phụ trách kiểm thử bước xác thực và thanh toán cho các phương thức thanh toán mới trên những luồng được giao: thẻ tín dụng GMO (3-D Secure), Amazon Pay, hoàn tiền, huỷ đơn, làm tròn thuế 8%/10% và khuyến mãi. Là một dự án cá nhân, tôi đã xây dựng Pocket QA — tiện ích Chrome phát hành trên Chrome Web Store, ghi lại thao tác của tester và phát lại thành các bài kiểm thử hồi quy. Pocket QA — Web Test Automation Extension

12/2025 – PresentNay

Role: QA / Developer · Solo projectVai trò: QA / Developer · Thực hiện độc lập

Self-built Chrome extension that records a tester's actions and replays them as regression tests, with a pass/fail result and a ready-to-paste bug report. Tiện ích Chrome tự xây dựng, ghi lại thao tác của tester rồi phát lại thành các bài kiểm thử hồi quy, kèm kết quả pass/fail và bug report sẵn sàng để dán.

  • 17 action types (iframes, assertions, conditions, branching); data-driven (CSV), sequenced and scheduled runs. 17 loại hành động (iframe, assertion, điều kiện, rẽ nhánh); chạy theo dữ liệu (CSV), chạy tuần tự và theo lịch.
  • Reports each run as Passed / Failed / Test broken, with a Markdown bug report (repro steps, screenshot), image diff and XLSX/HTML/ZIP export. Báo cáo mỗi lần chạy theo trạng thái Passed / Failed / Test broken, kèm bug report Markdown (các bước tái hiện, ảnh chụp màn hình), so sánh ảnh (image diff) và xuất XLSX/HTML/ZIP.
  • Built-in test design (Equivalence Partitioning, Boundary Value Analysis, decision tables); exports tests to Selenium (Python, Java), Playwright and Robot Framework. Tích hợp thiết kế test (Phân vùng tương đương, Phân tích giá trị biên, bảng quyết định); xuất test sang Selenium (Python, Java), Playwright và Robot Framework.
  • JavaScript ES6+
  • Chrome Extension MV3

  • SQL
